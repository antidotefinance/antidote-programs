# Security policy

Report vulnerabilities in these programs privately through GitHub security advisories:
https://github.com/antidotefinance/antidote-programs/security/advisories/new

Please do not open public issues, pull requests or discussions for vulnerabilities. Include the
program, the instruction, and steps or a transaction that reproduces the problem. We will
acknowledge the report in the advisory and coordinate a fix and disclosure there.

The security.txt embedded in each program (tilt-spot, levpad-hook, levfee, antidote-ideas) points
here. levcap has its own policy at https://github.com/antidotefinance/antidote-cap.
